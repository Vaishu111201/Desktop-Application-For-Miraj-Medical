# Desktop Application for Miraj Medical

## 📌 Project Overview

**Desktop Application for Miraj Medical** is a Java-based desktop application developed to manage the day-to-day operations of a small pharmacy.

The application helps manage **medicine inventory, billing, expiry tracking, sales records, and customer pending payments** through a simple and user-friendly interface.

It is designed as a lightweight **offline desktop solution** for small-scale pharmacies.

## ✨ Key Features

* 🔐 **User Login & Authentication**
* 💊 **Medicine & Stock Management** – Manage medicine name, quantity, price, batch number and expiry date.
* 🧾 **Billing System** – Generate bills with medicine details, quantity and total amount.
* 💰 **Pending Payment Management** – Maintain customer outstanding payment records.
* ⚠️ **Expiry Tracking** – Track medicines nearing or past their expiry date.
* 📊 **Sales & Stock Reports** – Maintain records for business management.
* 💾 **Offline Usage** – Application can run without an internet connection.
* 🖥️ **Simple User Interface** – Designed for easy use in a small pharmacy.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in **NetBeans IDE**.
3. Set up the required database in **MySQL Workbench**.
4. Configure the database connection in the Java application.
5. Make sure **MySQL Server** is running.
6. Build and run the project from NetBeans.
